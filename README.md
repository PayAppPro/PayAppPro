# PayAppPro

We build tools and open reference materials for **construction payment workflows**, with a focus on **AIA-style construction billing**, **G702 / G703 pay applications**, **Schedule of Values (SOV)**, **retainage**, **lien waivers**, and **progress billing**.

Our goal is to make construction billing clearer, more accurate, and easier to manage — both for contractors submitting payment applications and for developers building construction software.

---

## Open Reference Work

We maintain open, educational resources that document how AIA-style pay applications are commonly structured and calculated.

🔹 **AIA Pay Application Toolkit**  
https://github.com/PayAppPro/aia-pay-application-toolkit

That repository includes:

- Plain-English documentation for G702 and G703
- Realistic CSV and JSON examples
- Pay application schemas
- Billing logic notes (retainage, stored materials, progress vs. final billing)
- Construction billing workflow references

These materials are provided for **educational and reference purposes** and are not licensed AIA forms.

## PayAppPro

**PayAppPro** is a hosted software platform that helps contractors create accurate, consistent AIA-style pay applications and supporting billing documentation.

Key focus areas:

- G702 / G703 pay application workflows
- Schedule of Values (SOV) management
- Change order tracking
- Stored materials billing
- Automated calculations and rollups
- PDF generation and review-ready outputs

👉 https://payapppro.com

## Philosophy

Construction billing problems are rarely about intent — they're usually about:

- Inconsistent math
- Poor structure
- Manual processes
- Missing documentation
- Lack of visibility between detail and summary

We believe good tooling, clear workflows, and well-defined data models solve most of these issues.
